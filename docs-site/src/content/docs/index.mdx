## What is OpenMatter?

**OpenMatter** is the durable Agent Loop framework for work systems. A Loop is a built-in or user-defined process definition that repeatedly turns subscribed work events into terminal Reactions. OpenMatter constructs authorized context, binds work continuity to replaceable agent runtimes, and keeps every outcome explicit.

It is a framework and SDK—not a hosted agent brain, mandatory hub, OAuth platform, or connector marketplace. Storage, deployment, credentials, schedulers, work platforms, and agent runtimes remain replaceable.
