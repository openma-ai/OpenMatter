# `@openma/matter-gitlab`

GitLab for OpenMatter. Covers gitlab.com and self-managed GitLab.

| Import                       | Contents                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `@openma/matter-gitlab/bond` | Bond provider: OAuth (PKCE) user links, bot credentials, request classification, attribution, receive-pack parsing |

The Bond kernel it plugs into is `@openma/matter/bond`. See
[docs/BONDS.md](https://github.com/openma-ai/OpenMatter/blob/main/docs/BONDS.md)
for the flow, token custody, and security notes.
